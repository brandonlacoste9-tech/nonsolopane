# Non Solo Pane

Family Italian bakery site for Dorval — wood-oven pizza, panini, pastry, and gelato. English, French, and Italian.

## Local

```bash
npm install
cp .env.example .env.local
npm run dev
```

Set `ELEVENLABS_API_KEY` (and optional `ELEVENLABS_VOICE_ID`) for Mario’s voice. The Italian ambiance track plays without it.

## Stack

Next.js App Router, next-intl, Tailwind. Menu prices are from their Uber Eats card. Pizza is in-shop only.
